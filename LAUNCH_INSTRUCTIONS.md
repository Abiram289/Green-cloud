# 🚀 Launch Instructions - Enhanced VM Placement Web Application

This guide provides the definitive instructions for launching the project's primary interface: the interactive web dashboard.

---

## ✅ **Prerequisites**

1.  **Python**: Version 3.10 or higher.
2.  **pip**: The Python package installer.

---

## ⚙️ **Step 1: Install Dependencies**

Navigate to the project's root directory in your terminal and run the following command to install the required Python packages:

```bash
  pip install -r requirements.txt
```

This will install Flask, NumPy, Matplotlib, and all other necessary libraries.

---

## 🖥️ **Step 2: Launch the Web Server**

Once the dependencies are installed, run the following command to start the Flask web server:

```bash
  python start_webapp.py
```

You will see output in your terminal indicating that the server is running, typically on `http://127.0.0.1:5000`.

---

## 📊 **Step 3: Access the Application**

Open your web browser and navigate to the following URL:

- **`http://localhost:5000`**

The main project dashboard should load.

### **Recommended Next Steps**

1.  **View the Final Report**: Navigate to the **`/comparison`** page (`http://localhost:5000/comparison`) to see the definitive analysis of the `Hybrid-AI`'s superior performance.
2.  **Explore Host Management**: Visit the **`/hosts`** page to see the detailed, real-time status of the data center's host machines.
3.  **Explore Other Features**: Use the sidebar to navigate to the other pages, such as Tenant Management and the Audit Log.

---

## 🎉 **Launch Successful!**

If you can see the web dashboard in your browser, the launch was successful. You are now interacting with the complete, enhanced VM placement system.
