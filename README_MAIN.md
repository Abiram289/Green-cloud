# 🌟 Green Cloud - Enhanced VM Placement System

## Enterprise-Grade VM Placement Management with Web Interface

A comprehensive system for optimizing virtual machine placement in cloud environments, featuring advanced AI algorithms, multi-tenant support, and a professional web interface.

## 🚀 Getting Started

### **Prerequisites**
- Python 3.12 or higher
- pip (Python package manager)  
- Modern web browser
- Git (for cloning repository)

### **Installation**

1. **Clone the repository**
   ```bash
   git clone https://github.com/Abiram289/Green-cloud.git
   cd Green-cloud
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch web application**
   ```bash
   python start_webapp.py
   ```

4. **Access the interface**
   - 🌐 **Web Interface**: http://localhost:5000
   - 📊 **Dashboard**: Real-time system metrics
   - ⚙️ **VM Placement**: Interactive placement requests
   - 👥 **Tenants**: Multi-tenant management
   - 🛡️ **Audit**: Compliance monitoring
   - 📈 **Reports**: Advanced analytics

### **Alternative Demos**
```bash
# Run core algorithm demonstrations
python src/simulator.py              # Basic placement simulation
python src/enterprise_demo.py        # Multi-tenant enterprise demo
python src/model_trainer.py          # ML model training
python comprehensive_visualization.py # Advanced visualizations
```
